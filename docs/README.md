# Documentation

Design and planning notes for Yafa Express. The code is the source of truth for
what the game does; these pages record *why* it looks and sounds the way it
does, and what is still to come.

```
docs/
  design/
    2026-10-25-design-review.md   the review that replaced the "dark desk" look
    2026-10-26-sl-concept.md      the SL-inspired station & in-car interface
    demo/sl-concept.html          a browser demo of that concept (open directly)
  audio/
    sound-catalogue.md            every sound the game will have, and its file name
```

Dated files are decisions as they were taken. When a later decision supersedes
an earlier one, the earlier file gets a note at the top pointing forward; it is
never rewritten.

The task backlog that these notes feed lives in [`CLAUDE.md`](../CLAUDE.md) at
the repository root.
